# Design

Tropical modernist garden plan. Classy and muted. Values live as tokens in `styles.css`.

- **Signature:** the garden band (`UI.garden`). One bed per lesson section, filling with class time (teacher, projector) or finished sections (student).
- **Color:** palm shell `#153d35`, sea-mist ground `#eff4f1`, lagoon action `#1a665f`, sand for attention `#d8bc83`. Investing green, trading orchid, gambling terracotta. Claim blue, Evidence teal, Reasoning hibiscus. Bed colors are decoration and progress only.
- **Type:** Alegreya Sans 400, 500, 700, self-hosted, lining tabular figures. 18px body.
- **Surfaces:** flat, hairline borders, 8 to 10px radius. Only the student drawer casts a shadow.
- **Controls:** standard buttons, tabs, selects, tables. One filled button per decision.
- **Privacy:** the projector reads class state only. Never add names or student writing to it.
